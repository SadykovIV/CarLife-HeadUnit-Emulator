# Подключение телефона к HSD HeadUnit Emulator

В верхней панели выберите протокол, затем способ подключения. В сборке 0.6.0 Mac и Windows используют одни и те же приёмники. Настройки и отчёты предыдущего CarLife HeadUnit Emulator доступны в прежней папке приложения.

| Протокол телефона | Подключение | Видео и управление | Звук |
| --- | --- | --- | --- |
| CarLife | USB AOA, Wi-Fi | Профили Honda и версии с авторизацией, касания и функции приборки | Каналы CarLife |
| CarbitLink / EasyConnection | Wi-Fi или USB AOA | H.264 в формате RAW, один или два контакта | В HSD выводится отдельно по Bluetooth |
| WeLink A1 (WeDrive / Mapbar) | USB AOA | H.264, до двух контактов, клавиши Android | PCM, включая навигационный канал |
| Huawei HiCar | USB-сеть CDC-NCM | HiSight H.264, один контакт, «Домой» и «Назад» | AAC по DMSDP |

### CarbitLink

По Wi-Fi подключите оба устройства к одной локальной сети. В эмуляторе выберите **CarbitLink → Wi-Fi**, укажите сетевой интерфейс компьютера и нажмите **Подключить**. В HSD выберите **CarbitLink по Wi-Fi** и подключитесь. HSD ищет службу `_EasyConn._tcp`. Если в сети отключён multicast, в настройках CarbitLink на телефоне укажите показанный IPv4 компьютера. Обмен использует TCP 10930 на компьютере и TCP 10920–10922 на телефоне. Разрешите приложению доступ к этой локальной сети.

По кабелю выберите **CarbitLink → USB**, телефон в верхней панели и **Подключить**. На Android откройте предложенный аксессуар через HSD. Эмулятор запрашивает `Carbit / CarbitDriverOversea / 1.0`. В настройках HSD используйте обычный поток AVC (RAW). При переходе между приложениями, использующими AOA, завершите прежнюю сессию. Если телефон сохранил прежний аксессуар, переподключите кабель перед новым подключением.

### WeLink

Установленный на телефоне клиент должен поддерживать **WeDrive WeLink A1**. Выберите **WeLink → USB**, телефон и **Подключить**. Разрешите Android открыть аксессуар `Mapbar,Inc / WeLink / 1.0` в WeLink. Подтвердите захват экрана, если приложение запросит его. Эмулятор согласует кодек AVC и принимает поток PCM. Клиенты, требующие WeLink TLS, получат отдельное сообщение о несовместимом профиле. Это протокол проекции WeDrive, отдельный от Huawei WeLink для видеоконференций.

### Huawei HiCar

На телефоне включите USB-сеть NCM. Дождитесь, пока у её интерфейса на компьютере появится IPv4. В эмуляторе выберите **Huawei HiCar → USB NCM**, выберите адрес именно этой сети и нажмите **Подключить**. В HSD выберите **Huawei HiCar по USB (NCM)** и подключитесь. При отсутствии нового интерфейса нажмите **↻** после появления USB-сети в macOS или Windows.

Эмулятор объявляет Nearby на выбранном интерфейсе. При первом подключении код передаётся по кабелю, HiChain устанавливает пару. При повторном подключении обе стороны проверяют сохранённые ключи. Данные пары сохраняются в локальной папке приложения `hicar-pairing`. Режим требует уже работающий сетевой интерфейс NCM. Беспроводное подключение HiCar через Bluetooth/Wi-Fi в этой сборке отсутствует.

### Windows и диагностика

Для CarLife, CarbitLink и WeLink по USB откройте **Драйверы USB → Настроить WinUSB…**. У составного аксессуара `18D1:2D01` мастер настраивает интерфейс `MI_00`. Для ручной установки, в том числе на однофункциональный аксессуар `18D1:2D00`, в папку **Drivers** вложены Zadig со встроенным комплектом WinUSB и инструкция. Комплект работает без загрузок. [Инструкция для Windows](../windows/DRIVERS.ru.txt)

Для HiCar Windows 11 использует системный сетевой драйвер `UsbNcm.sys`. В Windows 10 понадобится совместимый драйвер CDC-NCM производителя. После появления сетевого адаптера выберите его IPv4 в эмуляторе. [Поддержка классов USB в Windows](https://learn.microsoft.com/windows-hardware/drivers/usbcon/supported-usb-classes)

В **Диагностика → Экспорт отчёта** доступны протокол, транспорт, этап соединения, счётчики декодированных кадров и отправленного ввода. Данные пары HiCar в отчёт не включаются.

### Сборка из исходников

Для сборки HiChain требуются CMake, Ninja, Perl, Make и компилятор C. На Apple Silicon используется Clang, для кросс-сборки Windows x64 — LLVM-MinGW с UCRT. Укажите путь к его каталогу bin через `HSD_MINGW_BIN`. Обычные сборщики приложения запускают сборку HiChain при необходимости. Проверенные архивы Mbed TLS, OpenSSL и cJSON можно заранее положить в каталог `HSD_HICAR_CACHE`. Версии и SHA-256 перечислены в `native/hicar/dependency-lock.json`. Готовое приложение содержит библиотеку и лицензии.
