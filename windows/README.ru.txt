CarLife HeadUnit Emulator 0.3.1 — Windows x64

1. Распакуйте ZIP целиком в обычную папку. Не запускайте приложение внутри ZIP.
2. Откройте CarLifeHeadUnitEmulator.exe. Python и Qt устанавливать отдельно не требуется.
3. Выберите USB-устройство в верхней панели и нажмите «Подключить».
   Режим AOA используется автоматически для выбранного устройства.
   Для проверки изображения, звука и управления без устройства выберите «Демо».

USB на Windows
Для доступа libusb интерфейс выбранного USB-устройства должен использовать
совместимый драйвер (обычно WinUSB). Обычный Android-драйвер ADB сам по себе
не гарантирует доступ. Для обычного режима до AOA и accessory после AOA могут
потребоваться разные привязки драйверов. Приложение драйверы не меняет.
Не меняйте драйверы USB-контроллеров, концентраторов или других устройств.
Документация: https://github.com/libusb/libusb/wiki/Windows

Проверка на Windows
Запустите Verify.cmd из командной строки: он проверит импорты Qt/PyAV,
наличие libusb и H.264-кодеков, без открытия USB и без смены его режима.
Локальная проверка приложения:
  CarLifeHeadUnitEmulator.exe --demo --smoke-test 8 --data-dir "C:\Temp\CarLife-Smoke"
Результаты: smoke-report.json и smoke-window.png в указанной папке.

Настройки и записи сессий: %LOCALAPPDATA%\CarLife HeadUnit
Папка сохранена для совместимости с версией 0.3.0.
При ошибке запуска: %LOCALAPPDATA%\CarLife HeadUnit\startup-error.txt
Снимки экрана и отчёты доступны из приложения.

Сборка проверяет SHA256 официального Python и всех wheel-пакетов, а также
формат AMD64 PE32+ каждого Windows-модуля. Факт запуска на Windows и тест
реального устройства подтверждаются отдельно: см. build-info.json.
EXE не подписан Authenticode; Windows может показать предупреждение издателя.
