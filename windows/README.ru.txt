HSD HeadUnit Emulator 0.6.0 для Windows x64

Распакуйте ZIP целиком и откройте HSDHeadUnitEmulator.exe. В верхней панели
выберите протокол и способ подключения. Для знакомства с эмулятором без
телефона выберите CarLife → Демо → Подключить.

CarbitLink работает по Wi-Fi или USB, WeLink A1 — по USB. Для Huawei HiCar
включите на телефоне USB NCM и выберите IPv4 появившегося сетевого адаптера.
Доступные способы подключения меняются при выборе протокола.

Если Windows видит телефон, но проекция по кабелю не запускается, нажмите
«Драйверы USB». Инструкция для вашего интерфейса и автономный установщик
находятся в папке Drivers.

Чтобы сохранить ошибку последнего подключения, откройте «Диагностика» →
«Экспорт отчёта». Verify.cmd проверяет запуск приложения и кодеки,
VerifyUsbRuntime.cmd — комплект драйверов и USB-библиотеку.
