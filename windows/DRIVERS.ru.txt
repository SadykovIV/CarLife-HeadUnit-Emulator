USB-драйверы для HSD HeadUnit Emulator

Распакуйте ZIP целиком. Сначала выберите протокол, телефон и «Подключить».
Если изображение появилось, настройка завершена. Для подключения по Wi-Fi
достаточно общей сети.

CarLife, CarbitLink и WeLink A1 по USB — WinUSB

1. Дождитесь перехода телефона в режим аксессуара Android (AOA). В Windows
   откройте «Диспетчер устройств» → свойства нужного устройства → «Сведения»
   → «ИД оборудования». Сверьте порт и идентификатор с эмулятором.
2. Для USB\VID_18D1&PID_2D01&MI_00 откройте в эмуляторе «Драйверы USB» →
   «Настроить WinUSB…». Мастер проверяет выбранный порт и интерфейс 0.
   Если мастер предложит назначить WinUSB или зарегистрировать уже назначенный
   драйвер, сверьте идентификатор в диалоге и подтвердите действие.
3. Для ручной установки в этой папке есть zadig-2.9.exe со встроенным комплектом
   WinUSB. Запустите его, откройте Options → List All Devices. Выберите запись
   с USB ID 18D1:2D01 и Interface 0 (MI_00). Справа выберите WinUSB и нажмите
   Install Driver или Replace Driver. Проверьте порт, если подключено несколько
   одинаковых телефонов. Продолжайте только когда запись однозначна.
4. При отключённой отладке Android может показать USB\VID_18D1&PID_2D00.
   Это аксессуар с одной функцией. Если обычное подключение сообщает об
   отсутствии WinUSB, в Zadig выберите этот точный ID на порту телефона
   и назначьте WinUSB. Для 2D00 отдельной строки MI_00 может не быть.
5. Вернитесь в эмулятор, нажмите ↻, выберите телефон и снова «Подключить».
   Если Windows попросит переподключить устройство, используйте тот же порт.

При 18D1:2D01 обрабатывается только Interface 0. MI_01 обслуживает ADB.
Составной родитель, MTP, модем и исходный USB ID телефона до перехода в AOA
используют свои драйверы. Если в списке есть только ADB, остановитесь на этом
шаге и откройте «Диагностика» → «Экспорт отчёта».
Для возврата предыдущего драйвера откройте свойства того же интерфейса
в «Диспетчере устройств» → «Драйвер» → «Откатить», если кнопка доступна.

Huawei HiCar по USB — сетевой адаптер CDC-NCM

1. Включите USB NCM на телефоне. В Windows 11 драйвер Microsoft UsbNcm входит
   в систему. В «Диспетчере устройств» откройте «Сетевые адаптеры» и проверьте,
   появился ли адаптер телефона после подключения кабеля.
2. Дождитесь IPv4 у этого адаптера. В эмуляторе выберите Huawei HiCar → USB NCM,
   нажмите ↻, выберите адрес USB-адаптера и нажмите «Подключить».
   Затем запустите подключение HiCar по USB в HSD.
3. Для Windows 10 потребуется совместимый сетевой драйвер CDC-NCM от
   производителя устройства либо компьютер с Windows 11. WinUSB и Zadig
   для HiCar не применяются.

Проверка комплекта

VerifyUsbRuntime.cmd в основной папке проверяет комплект Zadig, библиотеку USB
и наличие системных файлов WinUSB.sys и UsbNcm.sys. Привязку драйвера к телефону
проверяйте через меню «Драйверы USB» или свойства конкретного устройства.
Подпись файла zadig-2.9.exe принадлежит Akeo Consulting. Исходный код этой
версии и тексты GPL/LGPL находятся в licenses\Zadig.
